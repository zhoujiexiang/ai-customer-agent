# 价格保护规则

## 什么是价保

价格保护是指购买商品后，如果在规定时间内商品降价，用户可以申请退还差价。

## 价保期限

| 商品类型 | 价保期 |
| --- | --- |
| 自营商品 | 签收后 15 天 |
| 第三方商家商品 | 签收后 7 天 |
| 大促特价商品 | 不参与价保 |
| 秒杀、限时抢购商品 | 不参与价保 |
| 使用优惠券购买的商品 | 按实际支付价对比 |

## 申请条件

同时满足以下条件才能申请价保：

1. 订单已完成或已签收，且在价保期内
2. 商品当前售价低于购买时的实付价格
3. 商品处于有货状态（缺货、下架不参与）
4. 未申请过该订单的价保（一个订单只能申请一次）

## 差价计算方式

差价 = 购买时实付金额 − 当前售价

注意几点：

- 对比的是**实付金额**，不是商品原价。如果你购买时用了 50 元优惠券，那对比基准就是券后价格。
- 当前售价如果叠加了新的优惠券，按券后价对比。
- 运费不计入价保范围。

**举例**：商品原价 1000 元，你用券后实付 900 元。现在商品标价 950 元但可以直接用 100 元券，券后 850 元。那么差价是 900 − 850 = 50 元。

## 申请流程

1. 在「我的订单」找到对应订单
2. 点击「申请价保」
3. 系统自动核验当前价格，显示可退金额
4. 确认后差价在 1-3 个工作日退回原支付渠道

系统核验通过的会立即处理；核验不通过但你认为符合条件的，可以联系客服人工复核。

## 不适用价保的情形

- 平台大促活动期间的价格变动（大促价格本身就是活动价，不参与价保）
- 使用了限时秒杀、拼团等特殊促销形式
- 商品属于清仓、临期、瑕疵品等特价类目
- 会员专属价与普通价之间的差异
- 商品已经退货或正在退货流程中

## 常见问题

**Q：商品降价了但我刚过价保期两天，能通融吗？**
A：价保期是系统硬性规则，超过期限无法申请。建议在价保期内关注商品价格变动。

**Q：我用积分抵扣了一部分，差价怎么算？**
A：积分抵扣相当于现金优惠，计入实付金额。比如商品 500 元，用 10000 积分抵 100 元，实付 400 元，价保对比基准就是 400 元。

**Q：价保和退货可以同时申请吗？**
A：不可以。如果商品已经进入退货流程，价保申请会自动失效。建议先确认是否要退货，再决定是否申请价保。
