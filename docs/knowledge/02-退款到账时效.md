# 退款到账时效说明

## 退款处理流程

退款申请提交后经过三个环节：

1. **客服审核**：通常 24 小时内完成，大促期间可能延长至 48 小时
2. **商品验收**：退货商品寄回后，平台仓库签收并验收，需 1-3 个工作日
3. **财务打款**：验收通过后触发退款，由支付渠道完成资金退回

## 各支付渠道到账时间

| 支付方式 | 到账时间 |
| --- | --- |
| 微信支付 | 1-3 个工作日 |
| 支付宝 | 1-3 个工作日 |
| 银行卡（储蓄卡） | 3-7 个工作日 |
| 信用卡 | 3-7 个工作日，部分银行需等到账单日才会显示 |
| 云集余额 | 实时到账 |
| 货到付款 | 需提供银行卡信息，5-7 个工作日 |

说明：以上时间从平台财务打款成功开始计算，不含客服审核与商品验收时间。

## 常见的「已退款但没收到钱」

如果订单状态已经显示退款成功，但账户还没收到款项，通常是以下原因：

1. **信用卡入账延迟**：信用卡退款不会实时显示，银行一般在 1-2 个账单周期内冲抵。可以查询信用卡的「未出账单」或「已出账单」明细，通常会有退款记录。
2. **第三方支付渠道缓存**：微信和支付宝的退款记录需要手动刷新账单页面才能看到。
3. **退款到账原渠道**：如果下单时使用了组合支付（如余额加银行卡），退款会按比例分别退回原渠道，不会合并到单一账户。

## 退款金额计算

- 仅退款不退货：全额退还商品实付金额
- 退货退款：退还商品实付金额，运费按责任方判定
- 部分退款：按协商金额退还

优惠券、积分抵扣的部分不予退还现金，但优惠券在有效期内会返还至账户。

## 未收到退款的排查步骤

1. 在「我的订单」中确认退款状态是否为「退款成功」
2. 查询对应支付渠道的账单明细，注意查看时间范围要覆盖到退款日之后
3. 确认退款金额是否分批到账（组合支付场景）
4. 以上都确认无误后仍未收到，联系客服并提供订单号，客服会向支付渠道发起查询
