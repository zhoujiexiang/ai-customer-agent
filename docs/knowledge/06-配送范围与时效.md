# 配送范围与时效

## 配送范围

云集商城覆盖全国 31 个省级行政区（不含港澳台地区）。以下区域暂不支持配送或需额外确认：

- 部分偏远地区的乡镇及村级地址
- 新疆、西藏部分县市
- 内蒙古、青海部分牧区
- 军事管理区、政府机关等特殊区域

下单时系统会自动校验地址是否在配送范围，若提示「该地址暂不支持配送」，可联系客服确认是否有替代方案。

## 配送时效

| 区域 | 标准时效 |
| --- | --- |
| 江浙沪皖 | 1-2 天 |
| 华北、华中、华南主要城市 | 2-3 天 |
| 其他省会城市 | 3-4 天 |
| 偏远地区 | 5-8 天 |
| 新疆西藏 | 7-15 天 |

以上时效从出库时间开始计算，不含下单当日。大促期间（618、双 11 等）整体时效会延长 2-5 天。

## 发货时间

- 现货商品：付款后 48 小时内出库
- 预售商品：按商品详情页标注的发货时间
- 定制商品：按约定周期，通常 7-15 天
- 跨境商品：海关清关需要额外 3-7 天

## 运费标准

| 订单金额 | 运费 |
| --- | --- |
| 满 99 元 | 免运费（偏远地区除外） |
| 不满 99 元 | 12 元 |
| 新疆西藏 | 首重 25 元 |
| 大件商品 | 按实际物流报价 |

## 物流信息更新

物流轨迹一般每 4-6 小时更新一次。以下情况属于正常现象：

- 出库后 24 小时内无物流信息，属于快递揽收处理期
- 长途运输中可能出现 1-2 天无更新，属于正常运输状态
- 节假日期间物流更新会延迟

若物流信息超过 48 小时无更新，可联系客服发起物流查询。

## 签收注意事项

1. 建议在快递员在场时开箱验货
2. 发现外包装破损、商品损坏的，可当场拒收并拍照留证
3. 代收点签收视为本人签收，后续发现问题需走售后流程
4. 签收后 7 天内为退换货的有效申请期

## 配送异常处理

**快递显示已签收但没收到货**：
先联系快递员或派件网点核实，若确认丢失，联系客服申请补发或退款，平台会向快递公司发起调查，一般 3-5 个工作日有结果。

**地址填错需要修改**：
商品出库前可以在订单详情页自行修改地址；已出库的需联系客服尝试拦截，能否成功取决于包裹当前状态，无法保证。详见「修改收货地址」相关说明。
