# 售后处理时效与流程

## 各环节时效承诺

| 环节 | 承诺时效 |
| --- | --- |
| 在线客服首次响应 | 30 秒内 |
| 人工客服接入排队 | 3 分钟内 |
| 售后申请审核 | 24 小时内（大促期间 48 小时） |
| 退货商品验收 | 签收后 1-3 个工作日 |
| 退款打款 | 验收通过后 24 小时内 |
| 换货商品发出 | 验收通过后 48 小时内 |
| 物流异常查询反馈 | 3-5 个工作日 |
| 投诉处理答复 | 48 小时内给出方案 |

## 售后申请流程

**第一步：提交申请**
在「我的订单」中找到对应订单，点击「申请售后」，选择服务类型（仅退款 / 退货退款 / 换货 / 维修），填写原因并上传凭证。

凭证要求：
- 质量问题：清晰的商品问题照片或视频
- 少发漏发：外包装照片及开箱照片
- 商品不符：实物与详情页对比照
- 物流损坏：破损部位照片及快递面单

**第二步：客服审核**
审核人员会根据凭证判断责任归属。审核结果通过 App 推送和短信通知。

**第三步：执行**
- 退货：系统生成退货地址，用户寄回
- 换货：直接寄出新品
- 仅退款：直接触发退款流程

## 审核不通过的常见原因

1. 凭证不清晰，无法判断问题
2. 超过退换货期限
3. 商品属于不适用无理由退货的类目
4. 商品有明显的使用痕迹
5. 缺少必要的配件或包装

审核不通过会说明具体原因，用户补充材料后可以重新提交。

## 加急处理

以下情形可以申请加急：

- 商品是急需品（如药品、母婴用品）
- 已超过承诺时效仍未处理
- 同一问题重复提交超过 3 次未解决

申请加急需在客服对话中明确提出，客服会升级工单优先级。

## 超时未处理的处理方式

如果售后申请超过承诺时效仍未处理，可以：

1. 在对话中要求客服催办
2. 联系在线人工客服
3. 通过平台投诉入口发起投诉

超时本身不构成赔偿依据，但因平台原因造成的超时会酌情给予补偿，补偿形式通常为优惠券或积分。

## 争议处理

对审核结果有异议的，可以申请复核。复核由上一级客服主管处理，通常在 48 小时内给出结论。

涉及金额较大或责任认定困难的争议，可以申请平台介入调解，或通过消费者协会、市场监管部门等第三方渠道解决。
