# 优惠券使用规则

## 优惠券类型

| 类型 | 说明 | 示例 |
| --- | --- | --- |
| 满减券 | 订单金额达到门槛后抵扣固定金额 | 满 300 减 50 |
| 折扣券 | 按比例打折，通常有封顶金额 | 8.5 折，最高减 100 |
| 品类券 | 仅限指定品类商品使用 | 家电品类满 1000 减 150 |
| 单品券 | 仅限指定商品使用 | 某款手机专享 200 元券 |
| 运费券 | 抵扣运费 | 免运费券 |

## 使用规则

1. **单笔订单限用一张优惠券**，不可叠加使用（平台大促期间的跨店满减除外）
2. 优惠券可与积分抵扣同时使用，但积分抵扣不影响优惠券门槛的计算
3. 门槛计算的是商品原价总额，不含运费
4. 优惠券不可兑换现金，不可转让
5. 每张券有独立的有效期，过期自动失效，不予补发

## 优惠券的获取方式

- 每日签到领取
- 参与平台活动获得
- 会员等级权益发放
- 客服补偿发放（针对服务问题）
- 新用户注册礼包

## 退款时优惠券的处理

这是用户最常问的问题，规则如下：

**整单退款**：优惠券在有效期内会原路返还至账户，过期的不予返还。返还后的券有效期不变，仍按原到期时间计算。

**部分退款**：优惠券不返还。因为优惠券已经使用在整笔订单上，部分退款只退还实付金额的对应部分。

**举例说明**：
用「满 300 减 50」的券购买了两件商品，A 商品 200 元、B 商品 150 元，实付 300 元。
- 若退回 A 商品：退还 300 × (200/350) = 171.43 元，优惠券不返还
- 若整单退回：退还实付 300 元，优惠券在有效期内返还

## 优惠券失效的常见原因

1. 超过有效期
2. 商品不在券的适用范围（品类不符）
3. 订单金额未达到门槛
4. 与其他优惠互斥（特价商品不参与用券）
5. 商品已下架或库存不足

如果确认满足条件但无法使用，可以提供券码联系客服核查。
